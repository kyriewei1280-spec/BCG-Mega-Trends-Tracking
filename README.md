# Weekly Brief Atlas

An independent editorial synthesis of 69 unique Christoph Schweizer Weekly Briefs spanning May 2023 through August 2026.

## Publishing

This repository is a static website prepared for GitHub Pages. Serve the repository root from the `main` branch.

## Files

- `index.html` — website interface, interactions, and styles
- `weekly-brief-atlas-data.js` — cleaned 69-issue article archive and taxonomy mappings

This is an independent educational synthesis and is not an official BCG publication.
