# Weekly Brief Atlas

An independent editorial synthesis of 69 unique Christoph Schweizer Weekly Briefs spanning May 2023 through August 2026, supplemented by 10 Greater China TMT Daily Intelligence Briefs from August 10–27, 2026 and a curated library of authoritative external research.

## Publishing

This repository is a static website prepared for GitHub Pages. Serve the repository root from the `main` branch.

## Files

- `index.html` — website interface, interactions, and styles
- `weekly-brief-atlas-data.js` — cleaned 69-issue article archive and taxonomy mappings
- `tmt-daily-data.js` — cleaned 10-edition Greater China TMT Daily Brief archive used as a short-window signal layer in the TMT Industry Lens
- `authoritative-research-data.js` — curated report metadata, official source links, industry mappings, and megatrend mappings

This is an independent educational synthesis and is not an official BCG publication.
